# privacy-anonymizer-ru

![Offline](https://img.shields.io/badge/обработка-локальная-brightgreen.svg)
![LLM](https://img.shields.io/badge/LLM-Ollama-black.svg)

Обезличивание русскоязычных документов — маскирование персональных данных (ориентировано на РФ-сегмент).

Всё считается **локально, на машине пользователя. Никакие данные никуда не утекают, и это бесплатно.**

## Как это работает

Два независимых слоя, каждый включается своим флагом в конфиге:

1. **REGEX-слой** — чистый Python, детерминированно. Документные ПД, которые выводятся по формулам и регуляркам: ИНН, СНИЛС, паспорт РФ, банковская карта, телефон, email. Номера с контрольной суммой (ИНН / СНИЛС / карта по алгоритму Луна) проверяются — случайные совпадения цифр не маскируются.
2. **LLM-слой** — смысловые ПД, которые нельзя вывести скриптом: имена людей, организации, локации, адреса, логины. Локальная маленькая модель через [Ollama](https://ollama.com) поднимается, возвращает спаны в JSON и сразу выгружается из памяти (`keep_alive=0`). **Модель ничего не переписывает** — только находит.
3. **Мёрж и замена.** Спаны обоих слоёв объединяются, пересечения разрешаются по приоритету, замена на типизированные плейсхолдеры делается детерминированно в коде.

Гарантии качества:

- **Приоритет структуры над догадками.** При пересечении спанов структурные regex-ПД выигрывают у смысловых LLM-догадок; при равном приоритете побеждает более длинный спан. Порядок в тексте на выбор не влияет.
- **Защита от галлюцинаций.** Из ответа модели принимаются только строки, дословно встречающиеся в исходном тексте. Совпадение ищется по границам слова, чтобы «Иван» не совпал внутри «Иванов».
- **Жёсткая схема ответа.** Ollama грамматически ограничивает вывод по JSON Schema, поэтому модель физически не может вернуть невалидный JSON или тип вне списка категорий.
- **Мягкая деградация.** Если Ollama или модель недоступны — скрипт не падает, а работает только regex-слоем, предупредив об этом в stderr.

## Типы данных и плейсхолдеры

| Слой  | Тип        | Плейсхолдер      | Проверка                     |
|-------|------------|------------------|------------------------------|
| regex | `INN`      | `<ИНН>`          | контрольная сумма (10/12 цифр) |
| regex | `SNILS`    | `<СНИЛС>`        | контрольная сумма            |
| regex | `PASSPORT` | `<ПАСПОРТ>`      | код региона, не все одинаковые |
| regex | `CARD`     | `<КАРТА>`        | алгоритм Луна                |
| regex | `PHONE`    | `<ТЕЛЕФОН>`      | —                            |
| regex | `EMAIL`    | `<EMAIL>`        | —                            |
| regex | `URL`      | `<URL>`          | —                            |
| llm   | `PERSON`   | `<ИМЯ>`          | дословное вхождение в тексте |
| llm   | `ORG`      | `<ОРГАНИЗАЦИЯ>`  | дословное вхождение в тексте |
| llm   | `LOC`      | `<ЛОКАЦИЯ>`      | дословное вхождение в тексте |
| llm   | `ADDRESS`  | `<АДРЕС>`        | дословное вхождение в тексте |
| llm   | `LOGIN`    | `<ЛОГИН>`        | дословное вхождение в тексте |

Модель отдельно инструктируется **не** считать персональными данными роли и должности (продавец, консьерж, администратор), обобщения (пользователь, клиент, система), названия полей форм и элементов интерфейса, названия функций и продуктов.

## Требования

- Python 3
- `pip install requests`
- Установленный [Ollama](https://ollama.com) и модель — только для LLM-слоя:
  ```bash
  # macOS
  brew install ollama          # или .dmg с https://ollama.com/download
  # Windows
  winget install Ollama.Ollama # или установщик с https://ollama.com/download
  # Linux
  curl -fsSL https://ollama.com/install.sh | sh

  ollama pull qwen3:4b         # ~2.5 ГБ, dense, Q4_K_M
  ```

Автоскачивания модели нет — только подсказка в stderr. Сервер `ollama serve` скрипт поднимает сам, если тот не запущен, и гасит его на выходе; уже запущенный чужой сервер не трогает.

## Использование

```bash
python -m venv .venv && source .venv/bin/activate
pip install requests

# в файл
python privacy-anonymizer-ru.py входной.txt выходной.txt

# или в stdout, если второй аргумент не задан
python privacy-anonymizer-ru.py входной.txt
```

Служебные сообщения (предупреждения, «Готово: …») идут в stderr, поэтому результат из stdout можно спокойно перенаправлять в пайп.

## Настройка

Всё настраивается в блоке `КОНФИГ` в начале файла:

| Параметр                              | Значение по умолчанию              | Смысл                                                        |
|---------------------------------------|------------------------------------|--------------------------------------------------------------|
| `USE_REGEX_LAYER` / `USE_LLM_LAYER`   | `True` / `True`                    | включение слоёв по отдельности                               |
| `LLM_DEBUG`                           | `False`                            | печатать сырой JSON-ответ модели в stderr                    |
| `MODEL`                               | `qwen3:4b`                         | модель Ollama (`gemma3:4b` и т.п.)                           |
| `OLLAMA_HOST`                         | `http://localhost:11434`           | адрес сервера Ollama                                         |
| `LLM_TIMEOUT`                         | `600` сек                          | первый запрос включает холодную загрузку весов               |
| `LLM_CATEGORIES`                      | все пять                           | какие смысловые категории просить у модели                   |
| `PROTECT_URLS`                        | `False`                            | см. ниже                                                     |
| `PLACEHOLDERS`, `PRIORITY`            | —                                  | подстановки и приоритет при пересечении спанов               |

### Ссылки

Два взаимоисключающих режима, переключаются `PROTECT_URLS`:

- `False` (по умолчанию) — все ссылки маскируются целиком как `<URL>`. Хвостовая пунктуация в спан не включается, markdown вида `[текст](url)` не ломается.
- `True` — наоборот, ссылки защищаются: не маскируются сами и не дают другим слоям затронуть содержимое URL.

## Программное использование

Функция `sanitize_file_cached(in_path, cache_dir=".pii_cache")` возвращает путь к обезличенной копии файла. Кэш по SHA-256 содержимого: если файл не менялся, LLM повторно не запускается. Удобно для хуков — читать надо именно возвращённый путь, а не оригинал.

```python
from importlib import import_module
sanitizer = import_module("privacy-anonymizer-ru")

clean_path = sanitizer.sanitize_file_cached("secret.txt")
text = sanitizer.sanitize_text("Иванов Пётр, ИНН 500100732259")
```
