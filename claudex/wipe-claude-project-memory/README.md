# wipe-claude-project-memory

![Python](https://img.shields.io/badge/Python-3.8%2B-3776AB.svg?logo=python&logoColor=white)
![Dependencies](https://img.shields.io/badge/deps-stdlib%20only-brightgreen.svg)
![Platform](https://img.shields.io/badge/platform-macOS%20%7C%20Linux-lightgrey.svg)

Полное удаление всех данных, которые Claude Code накапливает о проекте, — чтобы «обнулить» его знания о конкретной кодовой базе.

Скрипт сканирует `~/.claude` и `~/.claude.json`, показывает таблицу известных проектов с объёмом накопленных данных, даёт выбрать нужные и вычищает всё, что Claude Code о них хранит.

## Что удаляется

| Данные                    | Где лежат                                          |
|---------------------------|----------------------------------------------------|
| Транскрипты сессий        | `~/.claude/projects/<slug>/`                       |
| История промптов          | `~/.claude/history.jsonl` (записи с `project == путь`) |
| Запись о проекте в конфиге| `~/.claude.json` → `projects[путь]`                |
| То же в бэкапах           | `~/.claude/backups/.claude.json.backup.*`          |
| Снапшоты правок           | `~/.claude/file-history/<sessionId>/`              |
| Окружение сессий          | `~/.claude/session-env/<sessionId>/`               |
| Todo / task / job / debug | `~/.claude/{todos,tasks,jobs,debug}/<sessionId>*`  |
| Служебные файлы сессий    | `~/.claude/{sessions,shell-snapshots,paste-cache}/*` |
| Временные файлы           | `/private/tmp/claude-<uid>/<slug>/`                |

`~/.claude.json` и `history.jsonl` не удаляются целиком — правятся точечно, вычищаются только записи выбранного проекта.

## Что НЕ трогается

**Файлы внутри самого проекта не трогаются.** Ни рабочий код, ни `.claude/` внутри проекта (`settings.json`, agents, commands, worktrees).

Это гарантируется не только логикой обхода, но и защитой в самой функции удаления: любой путь, лежащий внутри каталога проекта или вне белого списка каталогов с данными Claude Code (`~/.claude`, `/private/tmp/claude-<uid>`), отбрасывается.

В списке защищённых от удаления файлов также пользовательские настройки и глобальная память:

```
~/.claude.json
~/.claude/CLAUDE.md
~/.claude/settings.json
~/.claude/settings.local.json
~/.claude/keybindings.json
~/.claude/remote-settings.json
~/.claude/history.jsonl
```

## Требования

Python 3 и ничего больше — только стандартная библиотека.

## Использование

```bash
# интерактивный выбор из таблицы проектов
./wipe-claude-project-memory.py

# показать план удаления, ничего не удаляя
./wipe-claude-project-memory.py --dry-run

# снести данные обо всех найденных проектах без вопросов
./wipe-claude-project-memory.py --all --yes

# конкретные проекты по пути (флаг можно повторять)
./wipe-claude-project-memory.py --project /path/to/proj --project /path/to/other
```

Если бит запуска не выставлен — `python3 wipe-claude-project-memory.py …`.

В интерактивном режиме принимаются номера через пробел или запятую, диапазоны (`1-3`), `all` — все, `q` — выход.

### Флаги

| Флаг                | Что делает                                                              |
|---------------------|-------------------------------------------------------------------------|
| `--dry-run`         | показать план, ничего не удалять                                        |
| `--yes`, `-y`       | не спрашивать подтверждение                                             |
| `--all`             | выбрать все найденные проекты                                           |
| `--project PATH`    | путь проекта (можно повторять); отключает интерактивный выбор           |
| `--verify-deep`     | искать остаточные упоминания и в транскриптах других проектов (медленно)|
| `--no-verify`       | пропустить финальную проверку остаточных упоминаний                     |

## Поведение

- **Предупреждение о живых сессиях.** Если в выбранном проекте прямо сейчас запущена сессия Claude Code, скрипт скажет об этом с PID: такая сессия допишет свои данные при выходе, и часть удалённого вернётся. Для полной зачистки нужно выйти из неё и запустить скрипт снова.
- **Проверка остатков.** После удаления скрипт ищет остаточные упоминания проекта; `--verify-deep` расширяет поиск на транскрипты других проектов, `--no-verify` отключает проверку совсем.
- **Показ неприкосновенного.** Перед удалением печатается список путей, которые точно не будут затронуты.
