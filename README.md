**Сарай с инструментами.** Монорепозиторий с разношёрстными утилитами и приложениями — от маленьких CLI-скриптов до полноценных приложений под конкретные задачи. Каждый инструмент самодостаточен: живёт в своей папке, имеет свою инструкцию по запуску и не тянет за собой остальные.

Здесь нет единой темы. Есть общий принцип: если что-то оказалось полезным и переиспользуемым — оно едет сюда, в свой отсек, а не теряется по десятку разрозненных репозиториев.

## Инструменты

- **`claudex/`** — утилиты и приложения для тех, кто работает с Claude Code
  - [**wipe-claude-project-memory**](claudex/wipe-claude-project-memory/README.md) — полная зачистка всех данных, которые Claude Code накопил о проекте
- **`sllm/`** — скрипты с запуском маленьких моделей локально для решения одной узкой задачи, не привязанные к конкретной области
  - [**privacy-anonymizer-ru**](sllm/privacy-anonymizer-ru/README.md) — обезличивание русскоязычных документов: regex-слой + маленькая LLM через Ollama
  - [**uk-ru**](sllm/uk-ru/README.md) — ассистент для проверки и составления заявки в УК при проблемах в МКД

Список пополняется — новые полки заводятся по мере появления инструментов из новых областей.

## Как это устроено

- Каждый инструмент живёт в одноимённой папке внутри своей «полки» и документирует себя сам — `README.md` рядом с кодом.
- Новый инструмент едет в подходящую существующую полку; для новой области — заводится новая папка верхнего уровня.
- Корневой README не описывает инструменты, а только ссылается на них.
